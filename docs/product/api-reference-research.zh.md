# API Reference 查找需求

关联 [Issue #3579](https://github.com/goplus/builder/issues/3579)。

## 核心问题与改进方向

用户知道想实现的功能，或记得“数组”“遍历数组”等概念，却缺少直接查找对应代码写法的入口。当前面板没有搜索框，主要靠分类和滚动；用户需要先理解分类，或知道 API 名称，才能定位内容。

典型场景：想播放动画的用户输入 `play animation` 或“播放动画”，就应能找到 `animate` 等相关写法，不必先知道它属于“外观 → 动画”。忘记 API 名称或语法写法时，也应能通过记得的名称、概念或功能词查找。

改进方向是提供直接查找入口，覆盖 API 名称、中英文功能说明及必要别名。简短说明用于帮助用户识别搜索结果、区分不同写法。

## 实现依赖

复用现有条目、功能说明和插入能力，在前端增加搜索框与匹配逻辑，并补充中英文检索别名。首版无需新增后端接口、AI 服务或第三方搜索库。
