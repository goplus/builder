# 通用翻译 Translation

XBuilder 将代码编辑器中语言服务提供的代码诊断说明和文档说明翻译成用户选择的语言并展示。

## 背景

非英文用户查看代码时，诊断和文档说明仍可能以英文呈现。现有基于原文匹配的诊断翻译难以覆盖随代码变化的内容。本设计改由 builder 使用 AI 翻译语言服务返回的英文原文。

## 目标

* 让非英文用户以所选语言阅读诊断说明和文档说明。
* 同一套翻译能力可以处理多种语言服务内容，仅为每类消息维护少量翻译规则。
* 翻译不可用时仍能查看原文，不阻断代码编辑器的使用。

## 范围

本次覆盖代码编辑器 Hover 中的两类语言服务内容：诊断说明，以及类型、方法等定义的文档说明。两者均以英文原文为基础，仅在用户选择非英文语言时翻译。目前 XBuilder 仅支持英译中。

事件说明沿用现有文案；运行时终端说明不在本次范围内。

## 相关概念

### 诊断说明

诊断说明描述代码中的问题，内容可能随用户编写的代码而变化，例如错误消息中的变量名和类型名。

### 文档说明

文档说明是语言服务在 Hover 中提供的定义说明，包括类型和方法等。它通常由定义概览和说明文字组成，例如 `type int` 加上一段类型说明，或方法签名加上一段方法说明。

### 翻译

英文是语言服务内容的原始语言。用户选择英文时直接阅读原文；选择其他语言时，可以对诊断或文档说明发起 AI 翻译。翻译应保留原意及文中的代码标识符，不改写定义概览、链接等非说明内容。

### 译文与原文

用户语言为英文时只展示原文。用户语言为非英文时，点击“翻译”前只展示原文；翻译成功后同时展示译文和原文；翻译尚未完成或失败时仍只展示原文。

## 核心机制

### 翻译流程

诊断说明来自语言服务的诊断结果，文档说明来自语言服务的 Hover 结果；两者在前端组成用户看到的 Hover 内容。

用户点击“翻译”后，前端从相应结果中提取说明文字，结合该内容对应的代码上下文请求后端翻译。后端调用 AI，返回译文。

### 翻译上下文

诊断翻译可附带错误附近的少量代码，帮助 AI 区分普通单词与变量、类型等代码名称。文档翻译可附带当前定义的概览，例如类型名或方法签名，帮助 AI 确定说明对象。

前端通过 `domain` 指明内容所属领域，后端选择对应的 skill 文档辅助翻译。未提供 `domain` 时使用通用翻译规则，使同一接口也能处理其他内容。

### API 边界

本功能新增 `POST /translations`，请求包含：

* `content`：从 Hover 内容中提取的英文说明文字，不包含定义概览。
* `targetLanguage`：目标语言；当前仅支持简体中文 `zh-CN`。
* `contentType`：`diagnostic` 或 `documentation`，用于选择相应的翻译约束。
* `domain`：可选的领域标识；本次使用 `xgo` 或 `spx`。后端据此选择受控的技能参考材料，省略时使用通用翻译规则。
* `context`：可选的错误附近代码 `codeExcerpt` 或定义概览 `definition`，只用于消歧，不作为待翻译内容。

例如翻译方法文档时，请求和响应分别为：

```json
{
  "content": "SetDefaultKnowledgeBase sets the default knowledge base for AI players.",
  "targetLanguage": "zh-CN",
  "contentType": "documentation",
  "domain": "spx",
  "context": {
    "definition": "func SetDefaultKnowledgeBase(kb map[string]any)"
  }
}
```

```json
{
  "translation": "SetDefaultKnowledgeBase 设置 AI 玩家的默认知识库。"
}
```

翻译诊断说明时，请求和响应分别为：

```json
{
  "content": "opponent is not a type",
  "targetLanguage": "zh-CN",
  "contentType": "diagnostic",
  "domain": "spx",
  "context": {
    "codeExcerpt": "opponent ai.Player"
  }
}
```

```json
{
  "translation": "opponent 不是一个类型。"
}
```

### 错误处理

请求字段无效或目标语言不受支持时，后端返回 `400`；触发限流时返回 `429`；AI 服务不可用、超时或返回不可用的译文时返回服务端错误。

前端在任一翻译错误下仍显示原文。诊断和文档独立翻译，一处失败不影响另一处。

## User Story

### 理解诊断说明

用户语言为非英文时，编辑项目写出一段有类型错误的代码。悬停查看诊断时，先仅看到英文原文，点击“翻译“，完成后用户可对照阅读译文与英文原文；用户修改代码后，新的诊断说明需要重新翻译。

### 阅读文档说明

用户语言为非英文时，悬停在某个类型或方法上，先仅看到语言服务提供的英文文档。点击“翻译”，完成后用户可以对照阅读译文与英文原文，定义概览保持原样。
