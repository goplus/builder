# 课程作为 Project

作者可以通过项目地址打开一门课，编辑课程、预览草稿并发布版本。课程系列决定这门课在学习顺序中的位置。作者可以单独编辑课程，学员既可以从系列进入，也可以通过课程链接独立学习。

本设计将[项目类型](project-type.zh.md)应用于[教程 v2](tutorial-v2.zh.md)中的两种课程形态。统一的项目文件格式也让编辑器和后续 CLI 工具能够读写同一门课。

## 项目标识与内容

引导式课程和目标式课程的内容规格不同。引导式课程指定学员要打开的页面，并向 Copilot 提供引导指令。目标式课程是一个 XGo class framework 项目，由课程程序驱动学习流程。因此，创建、打开或导入项目时，可以根据 Project Type 确定课程格式。

| 项目类型 | 作者提供的内容 |
| --- | --- |
| `guided-course`（引导式课程） | 根目录的 `index.json` 保存入口 `entrypoint`，`prompt.md` 保存 Copilot 指引。入口可以指向一个独立的示例作品，也可以是 Builder 中的其他页面。 |
| `playground-course`（目标式课程） | 项目文件包含原有课程配置、`main_course.gox`、素材和内嵌的学员练习项目，保留原有相对路径。练习项目有自己的类型，例如 SPX。 |

两种课程都使用 Project 的显示名称和封面，通过 `owner/name` 寻址。同一 owner 下的项目名跨类型唯一，类型在创建后固定。例如，一门引导式课程和它打开的示例游戏各有自己的项目地址。XBP 包记录课程的 Project Type，导入时据此选择编辑器。历史 XBP 包缺少类型时仍按 Game 打开。

## 创作与发布

作者从课程管理页创建课程。在系列内新建一课时，使用与系列匹配的 Project Type。通用的「新建项目」入口继续创建游戏。课程管理页面和系列管理接口要求 `canManageCourses` 权限。课程项目本身沿用普通 Project 的权限规则，直接通过 API 操作时也一样。

作者在 `/editor/:owner/:name` 编辑课程，编辑器自动保存工作副本。预览在独立会话中运行当前草稿。需要发布修改时，由作者手动创建 Project release。

通过普通学习链接打开课程时，沿用项目详情页的规则，作者本人也一样。公开项目已有 release 时使用最新 release 的文件和封面；其他情况下，有访问权限的人读取当前 Project 数据。显示名称取自当前项目。以一门公开课程为例，**同一条学习链接**的行为如下：

| 作者操作 | 学员打开的内容 |
| --- | --- |
| 首次发布前保存课程 | 当前项目内容 |
| 发布 A | A |
| 编辑 B 并自动保存 | 学员仍学 A，作者可预览 B |
| 发布 B | B |

## 发现与学习

学员在教程页发现课程。社区首页、个人主页、搜索、探索等通用项目列表继续筛选 Game。直接访问 `/project/:owner/:name` 时，课程详情页展示封面、标题、作者、简介和「开始学习」按钮。

两种课程共用学习入口 `/project/:owner/:name/start`。引导式课程打开配置的入口并启动 Copilot 会话。目标式课程进入 `/project/:owner/:name/playground/:inPlaygroundPath*`。每位学员在当前会话中操作自己的练习项目，修改代码或重新开始练习都不会改变作者的课程或其他学员的练习。

## 系列归属与导航

课程可以独立存在，最多属于一个系列。系列只接受与其形态匹配的课程项目，并决定单元和课的顺序。从系列打开课程时，编辑链接和学习链接携带 `?series=<seriesID>`。确认课程属于该系列后，学习和编辑预览都可按系列顺序切换上一课、下一课，也可以跨单元切课。引导式课程跳转到配置的入口后，会话继续保留系列信息。独立课程链接省略系列导航。

在课程管理页删除系列时，也删除其中的课程。如果直接删除了某个课程项目，系列会跳过缺失的课程，其余课程仍按原有顺序排列。

## 迁移现有课程系列

从旧应用导出三个已维护的系列，离线转换后在新应用中导入。转换时保留课程标题、封面、系列和单元内的顺序、引导式课程的指引和入口，以及目标式课程的文件路径和素材引用。切换后学员使用新的学习链接。

转换后的包可以省略课程项目自身的 owner 和 name。导入时使用当前账号作为 owner，按 `course-<目标系列 ID>-<课程序号>` 命名。序号从 1 开始，跨单元连续编号；重名时追加数字后缀。后续调整课序时保留已分配的项目名。

导入时可为整包勾选「为导入的课程创建首次 release」。迁移现有三个系列时勾选此项，作者便可继续编辑下一个草稿，学员仍学习刚导入的版本。
