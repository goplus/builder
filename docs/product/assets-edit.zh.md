# 素材编辑

用户可以编辑当前 Project 中资源所用的图像和音频。确认修改后，改动会在该 Project 中所有使用这项资源的地方生效。

## 功能

### 编辑声音

用户可以裁剪音频、调整音量并试听。保存剪辑后，所有引用该 Sound 的地方都会播放编辑后的音频。

### 编辑造型

用户可以独立编辑 Sprite 造型列表中每个 Costume 的图片。用 AI 修改整张图片或指定区域时，每次成功的修改都会生成一版草稿。

采用草稿后，游戏立即使用选中的图片。AI 对照这版图片修订造型的生成描述，只更新本次编辑涉及的细节。修订后的描述存入该 Costume 的 Asset Setting，供下次生成该造型时使用。

### 编辑背景

用户可以用 AI 修改整张 Backdrop 图片或指定区域，并从生成的草稿中选择一版作为当前背景。

## User Story

### 剪辑多个动画共用的声音

用户为行走和落地动画选用同一个脚步声，剪去录音开头的空白、调整音量并试听。保存剪辑后，行走和落地动画都会播放剪辑后的脚步声。

### 用 AI 修改造型或背景

用户可以描述对整张图的修改，也可以指定一处或多处，分别说明修改要求。草稿随 Project 的编辑状态保存。重新打开 Project 后，用户可以从本轮开始时的图片或任一版草稿继续编辑。从较早版本生成的新草稿会取代该版本之后的草稿。

用户可以采用满意的一版，也可以放弃修改，保留本轮编辑开始时的图片。采用或放弃后，这张图片本轮的草稿都会清除。

导出 `.xbp`、发布项目或保存素材到素材库时，只带出这张图片在项目中生效的版本。改编项目沿用所选发布版本中的图片。
