# 素材编辑

用户可以在当前 [Project](./index.zh.md#项目-project) 中修改已有素材的图像、动画画面和音频内容。素材的增删、重命名以及常规属性配置（如动画时长与状态绑定等）见 [XBuilder](./index.zh.md) 和 [动画](./animation.zh.md)。

素材加入 Project 后，用户常需要结合游戏场景继续调整内容，比如剪掉录音开头的空白、改一下角色造型的配饰，或者调整背景里的局部画面。

裁剪音频、调整音量这类常规工具操作结果确定，保存后直接生效即可。用 AI 改图、改动画或改声音则耗时较长，结果也不一定符合预期，因此我们把 AI 编辑的结果先存为草稿，用户可以对比多个版本、退回之前的版本重改，满意后再采用。

素材内容改过之后，原有的 [Asset Setting](./assets-gen.zh.md#素材设定-asset-setting) 也可能与内容对不上，需要跟着更新，否则后续继续生成或保存到素材库时用的还是旧描述。

## 功能

* Costume 编辑
  - AI 编辑：整体或局部修改造型画面
  - 直接编辑（规划中）：裁剪画面、调整图片大小与偏移等
* Backdrop 编辑
  - AI 编辑：整体或局部修改背景画面
* Sound 编辑
  - 直接编辑：裁剪音频、调整音量并试听
  - AI 编辑（规划中）：修改语音、音效或背景音乐内容
* Animation 编辑
  - AI 编辑（规划中）：调整动画动作或局部画面

## 基本概念

### 编辑目标

素材编辑的对象是当前 Project 中的 Costume、Backdrop、Animation 和 Sound。编辑只影响当前 Project，不会改动素材库中已有的 [Asset](./index.zh.md#素材-asset)；对象的 Name、代码引用及状态绑定也保持不变。

### 编辑方式

* 直接编辑：用编辑器工具调整内容，保存后直接在 Project 中生效
* AI 编辑：根据修改要求生成候选版本，任务状态与额度规则同 [Asset Generation](./assets-gen.zh.md#素材生成-asset-generation)；结果先存为 Draft，确认采用后生效

### 草稿 Draft

每次成功的 AI 编辑都会生成一版 Draft，包含这次修改的输入和生成的完整目标对象。

对于每个编辑目标，本轮编辑包括以下信息：

* 原始版本：本轮编辑开始前的对象
* Drafts：按生成顺序排列的 Draft 列表
* 当前选中的版本：原始版本或其中一版 Draft

用户采用或放弃之前，进行中的 AI 编辑任务和 Draft 会随 [Project](./index.zh.md#项目-project) 保存，只有项目拥有者下次在编辑器中打开 Project 时才会恢复，但它们不进入 Project 的 Game 内容。Draft 只在当前对象的编辑界面里预览和对比，关闭编辑界面或保存 Project 都不会让它生效。

## 核心机制

### 直接编辑

调整过程中支持实时预览或试听；取消时恢复修改前状态，保存后更新目标对象并记入撤销/重做历史。

### AI 编辑

AI 编辑的输入包括：

* 当前选中的版本
* 修改要求：针对整体的修改说明，或指定一处或多处局部位置并分别说明修改要求
* 当前 Project Setting，以及所属 Sprite、Backdrop 或 Sound 的 Asset Setting

每次生成的结果是完整的目标对象。除了新的图像、动画帧或音频，相关配置也会一起更新并存入 Draft：

* Costume：按新图像更新分辨率和参考点（Pivot），使造型在舞台上的显示大小和对齐位置不变
* Animation：按新动画更新帧序列和 Duration

### 草稿回退与采用

用户可以在原始版本和各版 Draft 之间切换预览，也可以基于当前选中的任一版本继续用 AI 修改。如果切回原始版本或较早的一版 Draft 重新生成，新生成的 Draft 会接在那一版后面，替换掉它之后原有的 Draft；如果生成失败或中途取消，已有的 Draft 保留不变。

确认采用时，用当前选中的 Draft 替换原对象，并记入编辑器的撤销/重做历史；选择放弃时保留原对象不变。采用或放弃都会结束本轮编辑，并清掉该对象的 Draft。

### Asset Setting 同步

在 Project 中，只有可独立保存为 Asset 的 Sprite、Backdrop、Sound 会保留各自的 [Asset Setting](./assets-gen.zh.md#素材设定-asset-setting)，Costume 和 Animation 不单独保存。这些对象的内容变化生效后，XBuilder 会在后台更新对应的 Asset Setting，不影响用户继续编辑和运行游戏：

* Backdrop、Sound：按修改后的实际内容更新 Asset Setting；原本没有设定的素材（如本地上传的文件）会根据当前内容补上一份设定
* Sprite：Asset Setting 只记录其下各 Costume 和 Animation 共有的特征。这些子项被编辑或增删后：所有子项都变化的特征随之更新；彼此不再一致的特征改为更宽泛的描述；原有子项全部被换掉时，按新内容重新生成设定

## User Story

### 裁剪并试听录音

用户录了一段角色配音添加为 Sound，试听时发现开头有空白且音量偏小。他在声音编辑器里裁掉开头空白、调高音量并重新试听，保存后这份 Sound 立即更新。

### 用 AI 修改角色造型并继续生成动作

用户生成了一个设定为“戴红围巾的狐狸”的 Sprite，打开默认 Costume 让 AI 把围巾改成绿色。试着改了两版后关掉页面，重新打开 Project 时之前的草稿还在；他切回第一版草稿重新生成，新结果替换了原本的第二版。

他采用了满意的一版，Sprite 换上新造型，本轮草稿随之清掉，角色在舞台上的显示大小和对齐位置不变。随后 XBuilder 在后台更新这个 Sprite 的 Asset Setting：如果其他造型还是红围巾，设定改为“戴围巾的狐狸”；如果所有造型都换成了绿围巾，则改为“戴绿围巾的狐狸”。之后再为这个 Sprite 生成跑步 Animation 时，会以更新后的设定和新造型为依据。
