# XBuilder IDE 文案

1. **清楚**：说清发生了什么，按钮写实际动作，同一对象和动作统一用词。
2. **可靠**：只说能确认的事实，有风险先说清后果。
3. **尊重**：像创作伙伴一样平等沟通，不责怪用户，把选择留给用户。
4. **实用**：只给当下需要的信息，有可执行的下一步再说。

## 标点自查

- 中文对象名、操作名和界面项需要加引号时，统一用 `“ ”`。例如：`撤销“移动精灵”`。英文按句式用半角双引号，或用冒号引出名称。
- 完整句子加句号，短语不加。例如：`请输入项目名。` / `Enter a project name.`，`删除` / `Delete`。菜单省略号按 [菜单项规则](../../gui/AGENTS.md#menu-item-text-guidelines) 处理。
- 错误提示先看最终显示方式：括号中补充的失败原因用不带句号的简短片段。独立显示的校验和操作提示，仍按完整句子或短语处理。
